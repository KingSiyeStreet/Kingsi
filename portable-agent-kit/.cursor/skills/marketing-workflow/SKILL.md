# Workflow marketing

L’utilisateur est marketeur. Il veut des tâches **terminées**, pas des idées en vrac.

## Séquence obligatoire

1. **Objectif** — audience, offre, canal, contrainte (langue, ton, deadline). Si un seul point manque et bloque le livrable, pose **une** question. Sinon avance avec une hypothèse explicite.
2. **Recherche** — faits avant copy.
   - Web pour le marché, le vocabulaire, les pages concurrentes.
   - Skill `x-research` si la tâche touche X / Twitter.
   - MCP Aleph si la tâche touche finance, métriques, ou reporting.
3. **Plan** — 3 à 7 étapes max.
4. **Exécution** — brief, calendrier, copy prêt à coller, ou memo de veille sourcé.
5. **Preuve** — sources cliquables. Distinguer **fait observé** vs **recommandation**.

## Règles de contenu

- Français par défaut, tutoiement, ton direct.
- Pas de jargon vide sans preuve.
- Ne pas publier sur X : livrer le texte + un mode d’emploi de publication humaine.
- Ne pas inventer de chiffres, de followers, ou de citations.
- Si X ou Aleph n’est pas authentifié, le dire et continuer avec les sources encore disponibles.

## Livrables types

| Demande | Livrable |
| --- | --- |
| Idée de contenu | 5 à 10 angles + 1 pièce rédigée à fond |
| Campagne | objectif, audience, message, canaux, 1 semaine d’actions |
| Veille | synthèse, citations, implication pour **ce** dépôt |
| Page / offre | copy structuré (accroche, preuve, CTA) |
